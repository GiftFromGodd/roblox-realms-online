# Robux Realms — Fantasy Adventure

A playable browser-based, third-person fantasy adventure prototype designed to stay lightweight for Chromebooks.

## Run on Render
- Build command: `npm install`
- Start command: `npm start`
- Root directory: leave blank unless you put the project in a subfolder.
- Make sure `index.html`, `server.js`, and `package.json` are in the repository root.

## Play
- WASD / arrow keys: move
- Mouse drag: rotate camera
- Shift: sprint
- Space: jump
- E: interact with nearby quest characters / chests
- Q: use a healing potion
- On-screen joystick/buttons are provided for touch devices.
- Collect glowing crystals, open treasure chests, complete the village quest, and reach the ancient shrine.

This is a single-player prototype. R-Coins and items are local demo progress only; there is no real-money gambling, persistent account system, or multiplayer backend.

The game uses Three.js from a CDN, so an internet connection is required.
